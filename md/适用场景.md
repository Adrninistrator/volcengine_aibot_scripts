# 适用场景

本工具面向两类使用者：运营人员（日常操作提效）与 AI 助手（自动化闭环）。

# 运营人员的日常操作

一类是运营人员在火山引擎智能外呼管理台**日常的运营操作**，例如：

- 查询项目组、查询项目组下的剧本；
- 根据剧本ID查询剧本、根据剧本名称搜索剧本；
- 剧本话术变量修改、检查；
- 下载（导出）并检查剧本内容；
- 导入修改后的剧本；
- 发布剧本测试版本；
- 查询剧本基本信息（剧本类型、最大对话轮次、LLM 模型、ASR 设置、挂载的信息抽取/线索定级/通话总结分析Agent、测试与线上版本发布状态）；
- 查询分析Agent列表与内容，检查不同项目组的剧本是否共用同一个分析Agent、提示词内容是否符合业务要求；
- 批量导出某个或全部项目组的剧本，并在导出内容中按关键字搜索（例如排查某句话术在哪些剧本中出现）。这些操作原本需要在管理台页面逐个点击，现在可以用一条自然语言指令完成，结果自动保存到本地 result 目录，便于留档与复核。

# AI 完成剧本优化闭环

最主要的功能是**将火山引擎智能外呼管理台页面的「文本对话测试」功能向 AI 开放**，使 AI 能够完成：

```
剧本分析 → 剧本修改 → 剧本导入 → 剧本发布 → 对话测试
```

的完整闭环，提高剧本优化的运营效率。例如：

1. **剧本分析**：导出剧本并检查变量配置、提示词内容是否满足要求；配合剧本基本信息与 Sub Agent 提示词查询，可从剧本配置层面定位问题（如 ASR 热词、挂机关键词、模型选择）；
2. **剧本修改**：按运营要求修改变量定义或变量取值（修改前自动备份
 剧本与变量当前值）；
3. **剧本导入**：把修改后的剧本导入为新的测试剧本；
4. **剧本发布**：发布测试版本使修改生效；
5. **对话测试**：AI 扮演客户与机器人多轮对话，验证话术效果，每轮对话自动保存变量与对话全文，便于逐轮分析。

# 规划中的功能

提供根据以下条件查询历史对话文本与变量的功能：

- 剧本、时间；
- 意向等级、通话时长；
- 是否命中语音助手等。查询结果仅展示各变量为空还是非空，使 AI 能够**自主分析对话效果**，进一步提升剧本优化效果，并支持分析有业务价值的数据。

# 典型使用角色

| 角色 | 用法 |
|---|---|
| 运营人员 | Web 页面 + 独立脚本（命令行一键执行，结果落盘） |
| AI 助手 | MCP 服务（SSE），按自然语言指令闭环执行 |
| 剧本优化 | 对话测试 + 变量修改 + 发布的组合流（建议测试环境账号） |

# 安全与资源

- 修改类操作有账号守卫（只允许配置的账号执行），建议使用测试环境账号；
- 文本对话测试占用生产实际外呼资源，控制并发、建议晚上测试。
