# 使用说明

本工具把火山引擎智能外呼管理台的常用运营操作转换为脚本与 MCP 服务，让 AI 能以自然语言驱动「查询 → 修改 → 导入 → 发布 → 对话测试」的完整闭环。

# 基础依赖

## Python

- Python 3.10 及以上（推荐 3.12）；
- 依赖库由 `install.bat` 自动安装到项目虚拟环境 `.venv`（requests / mcp / uvicorn / sse-starlette / websockets），无需手工 pip。

## 网站Cookie提供工具

当前工具在调用火山引擎智能外呼网站接口时，依赖 chrome_capture_operate 提供 Cookie 以使用当前人员身份。工具地址为：

- https://github.com/Adrninistrator/chrome_capture_operate
- https://gitee.com/adrninistrator/chrome_capture_operate

需要安装 chrome_capture_operate，**在使用本工具期间，要保证 chrome_capture_operate 也在运行**（默认监听 `http://127.0.0.1:33445`），并且日常 Chrome 已登录火山引擎智能外呼控制台（插件会把登录 Cookie 推送给 chrome_capture_operate）。

chrome_capture_operate 的参考文档见以上项目的 README.md 或 chrome_capture_operate_python/usage/usage.md。

对于 chrome_capture_operate 需要执行的操作如下：

| 归属 | 操作 | 执行方式 |
|---|---|---|
| Git项目 chrome_capture_operate | 下载到本地 | 人工或AI执行 |
| Chrome浏览器插件 chrome_capture_operate_extension | 安装 | 人工（由于Chrome的安全限制，只能人工安装） |
| Chrome浏览器插件 chrome_capture_operate_extension | 配置Cookie推送范围为全部允许，或按指定范围推送且指定 *.volcengine.com | 人工（由于Chrome的安全限制，只能人工配置） |
| Python脚本 chrome_capture_operate_python | 通过install.bat安装 | 人工或AI执行 |
| Python脚本 chrome_capture_operate_python | 通过start.bat启动 | 人工或AI执行 |

Python脚本 chrome_capture_operate_python 可以设置为随操作系统自启动。

> 常见问题：如果提示“Cookie 服务不可达”或“获取 Cookie 失败”，请先检查 **chrome_capture_operate 是否正在正常运行**（浏览器访问 `http://127.0.0.1:33445/`，或看本工具日志），再确认 Chrome 是否已登录火山引擎控制台、插件推送范围是否允许 volcengine.com。

# 获取工具

工具地址为：

- https://github.com/Adrninistrator/volcengine_aibot_scripts
- https://gitee.com/adrninistrator/volcengine_aibot_scripts

获取方式（任选其一）：

- Git 下载：`git clone` 以上仓库到本地；
- 或直接下载项目压缩包解压到本地目录。

chrome_capture_operate 的获取地址见上文「基础依赖」。

# 安装

双击项目目录下的 `install.bat`：

- 自动创建虚拟环境 `.venv`（已存在则复用）；
- 安装全部 Python 依赖；
- 完成后窗口会提示 "install done"。

# 启动

双击项目目录下的 `start.bat`：

- 使用 pythonw 后台运行，**不弹出应用窗口**；
- 桌面右下角出现系统托盘图标：**双击打开本页面**，右键菜单可「打开配置页 / 退出」；
- 同一个端口同时提供 Web 页面与 MCP SSE 服务（默认 19000，可在「配置参数」标签页修改，修改后需重启生效）；
- 启动脚本会自动检查端口占用并做启动自检，失败时提示查看 `log\startup.log`。

# 安装MCP服务

在命令行执行（把端口换成实际配置的端口）：

```bash
claude mcp add --scope user --transport sse volc-aibot http://127.0.0.1:19000/sse
```

- 注册后即可在 Claude Code 中使用自然语言驱动本工具；
- 也可以在「MCP接口」标签页查看当前支持的全部 MCP 接口（名称、描述、参数），页面上提供复制按钮；
- 不确定怎么用时，先让 AI 调用 `usage_guide` 工具。

# 配置修改操作允许执行的账号

在「配置参数」标签页设置「修改操作允许操作的账号」（只允许一个）。

- 所有**修改类操作**（发布剧本测试版本、剧本变量修改、测试版本全局变量赋值）执行前都会校验当前 Chrome 登录账号：不一致则拒绝执行，避免误改；
- 查询类操作不受限制；
- **建议配置测试环境的账号**：在测试环境完成剧本修改后，再人工导入到测试环境使用的账号，以保证生产环境账号数据不被 AI 误修改；
- 可通过「获取当前登录的账号」脚本（`scripts\get_current_user.py --save-allowed`）查看并一键保存当前账号。

# 通过自然语言与AI对话

安装 MCP 服务后，在 Claude Code 中直接用自然语言描述需求，例如：

```
使用 volc-aibot MCP：检查剧本 llm_xxx 的变量，把座席工号改成 123456
```

# 剧本基本信息与分析Agents查询

可通过自然语言让 AI 调用对应 MCP 工具，也可直接运行脚本：

- **查询剧本基本信息**（类型/最大对话轮次/最大模型出错次数/挂机关键词/LLM 模型/ASR 设置/非真人接听识别开关与播报内容/挂载的分析Agents/测试与线上版本发布状态）：`scripts\query_script_info.py llm_xxx`；
- **查询分析Agent列表**（名称/ID/状态 已发布或未发布/更新时间）：`scripts\query_analysis_agents.py`（`--type 通话总结/信息抽取/线索定级` 可选过滤）；
- **获取分析Agent内容**（系统提示词/用户提示词/状态/模型参数，提示词全文落盘 result 目录）：`scripts\get_analysis_agent.py BDE44205003`；
- 分析Agents 位于独立的 CloudLadder 服务域，由本工具自动完成鉴权（用火山登录态换取访问令牌），使用方式与其它功能一致。

# 快捷工具（Web页面）

「快捷工具」标签页提供三个免命令操作（左侧列表切换）：

- **批量查询剧本信息**：选择全部或某个项目组，一键查询其下全部剧本的基本信息（字段与「查询剧本基本信息」一致），可选**并发数**（默认 5，获得剧本清单后并行查询，提速数倍；过大有服务端频控风险），结果可**复制**（\t 分隔文本，可直接粘贴到 Excel）或**导出为 Excel 文件**（首行冻结、支持筛选，文件名含导出时间）；
- **批量搜索剧本内容**：先按项目组**批量导出**剧本（生成以「_批量导出剧本」结尾的结果目录，目录列表展示各目录已导出的剧本数，可选并发数），再选择导出目录、输入关键字（可选统计出现次数）搜索，列出每个剧本（项目组/剧本ID/剧本名称/剧本类型）是否命中及次数，同样支持复制与导出 Excel（首行冻结、支持筛选，文件名含导出时间）；
- **批量下载搜索分析Agent**：按类型**批量下载**当前账号的分析Agent系统提示词（生成以「_批量下载分析Agent」结尾的结果目录，目录列表展示各目录已下载的分析Agent数，可选并发数），再选择下载目录、输入关键字搜索提示词，列出各分析Agent是否命中及次数，支持复制与导出 Excel（首行冻结、支持筛选，文件名含导出时间）。

这些操作执行时间可能较长。快捷工具页**上方的执行状态面板**（随左侧工具切换对应数据）通过 WebSocket 实时展示：**未展开时仅显示百分比进度条**（按总数/已完成数，如「12/68（18%）」）；点击右侧醒目的**「展开详情 ▾」按钮**展开后显示当前正在执行的请求与已耗时、当前处理的剧本ID/剧本名称（或分析Agent）等参数与最近事件；操作**完成时面板显示绿色「✓ 已完成」提示与总耗时**，若浏览器当前不在本页面，标签页标题会闪烁提醒（回到页面即停），按钮旁也会显示结果摘要。连接断开自动重连，无需刷新页面。同样的请求与耗时也会逐条记录在 log 目录的日志文件中（含 HTTP 方法/URL/返回码/耗时/返回包大小，异常含完整堆栈），便于排障。

更多按场景整理的提示词，见「提示词示例」标签页；典型业务场景见「适用场景」标签页。

# 注意事项

- **对话测试的会话变量**：start_dialog 的 overrides（脚本 `--var`，可重复传入以一次指定多个变量）为**会话级变量**，仅在每段对话首次请求时生效且整段会话不变，会覆盖剧本测试版本全局变量的同名变量（不改测试版本全局变量）；未指定时使用剧本测试版本全局变量；
- **测试版本全局变量赋值**：必填变量（查询变量时 is_required 为 true 的）赋值时值不能为空，传空值会被拒绝并提示；
- **文本对话测试占用生产实际外呼资源**：不要使用太大的并发，避免业务高峰，建议在晚上测试；
- 对话记录、导出文件等结果保存在项目 `result` 目录（每次运行一个「时间_账号_功能」子目录，目录名中的账号用于区分环境）；
- 运行日志在 `log` 目录（每天一个文件），排障时可查看。
